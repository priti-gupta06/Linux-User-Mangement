create a safe practice environment to understand user , group and access permission.


Internship Task 20: Linux User Management

Overview

This task focuses on understanding basic Linux user management, user identity, groups, and file permissions using the JSLinux Buildroot Linux Console.

Objective

- Understand basic Linux commands.
- Learn about Linux users and groups.
- Understand file permissions and root access security.
- Explore basic account management commands.

Tools Used

- JSLinux
- Buildroot Linux Console
- Linux terminal

Commands Practiced

- "whoami" — Displays the current username.
- "uname -a" — Displays system information.
- "pwd" — Displays the current directory.
- "ls" — Lists files and directories.
- "cat hello.c" — Displays source code.
- "gcc --version" — Displays compiler information.
- "./hello" — Executes the compiled program.
- "id" — Displays user and group identity information.
- "adduser student1" — Attempts to create a practice user.

Key Learnings

- Linux uses user accounts to manage access.
- Groups help assign shared permissions to users.
- File permissions control reading, writing, and executing files.
- Root access should be restricted because it provides administrative privileges.

Limitations

The practical was performed in the JSLinux Buildroot environment. The "addgroup" command was unavailable, so group creation and permission testing could not be completed.

Result

Basic Linux commands were executed, and a C program was compiled and run successfully. The practical introduced fundamental concepts of Linux users, groups, and access control.

Conclusion

This task provided introductory knowledge of Linux terminal operations and account management. A full user and group management practical requires a Linux environment with the necessary administration utilities.
